# ARWay

AR walking navigation prototype backbone.

## Requirements
- This project utilizes the user's camera and geolocation.
- Accessing device hardware such as camera and GPS **requires HTTPS** for security reasons. Vercel provides this automatically upon deployment. If you run this locally, you must view it on localhost or configure local HTTPS.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
